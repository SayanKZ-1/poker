# Проверка СВОИ 0.3.0

Проверка выполнена 22 сентября 2026 года. Это проверка прототипа, не сертификация, аудит безопасности или доказательство отсутствия всех ошибок.

## Node.js / сервер

`npm test` — **73 теста, 73 успешны, 0 ошибок**. Фактический вывод: `docs/test-output-v0.3.txt`. Тесты выполнялись Node.js 22.16.0. У runtime нет внешних npm-зависимостей.

Новые проверки: однократный запуск, серверный шестисекундный отсчёт, отсутствие двойной раздачи, пас и sit-out по таймеру, бесплатный чек также превращается в автопас по выбранному профилю; явное возвращение и его отмена; невозможность оживить текущую руку; ожидание BB после пропуска; короткий кэш-стол и два возвращающихся; продолжающиеся турнирные блайнды; сохранение права на банк для олл-ина; краткое отключение без сброса таймера; пауза после выплаты и заморозка турнирных уровней; конец турнира; сохранение последней руки с персональным сокрытием карт; остановка при ошибке.

Проверены также смешанные последовательности ухода/возвращения/таймаутов на протяжении 250 кэш-рук и до 250 турнирных рук (турнир может закончиться раньше), с проверкой сохранности фишек и ограниченного числа шагов. Это не исчерпывающий перебор всех раздач.

HTTP/SSE-тесты запускают настоящий локальный Node-сервер: следующий handId меняется по серверному таймеру без команды start и при закрытом потоке хозяина. Проверены запрет паузы посторонним участником, отсутствие возможности направить sit-out/return на чужое место, повтор/подмена requestId, устаревшая версия, приватность прошлой руки, продолжение после паузы. Используются тестовые dev-идентичности, не реальный Telegram-бот.

Прежние проверки комбинаций, распределения банков, авторизации и случайных раздач также входят в эти 73 теста. Исчерпывающий перебор всех пятёрок в этом обновлении отдельно не повторялся; прежние доказательные файлы версии 0.2 сохранены как исторические, см. `docs/VALIDATION-v0.2.md`.

## Браузер

Автономный HTML реально выполнен Chromium через Playwright с виртуальными часами. Проверены: первый запуск, отсутствие кнопки ручной следующей раздачи; обратный отсчёт; пауза/продолжение и переход handId; просмотр прошлой руки; таймаут пользователя и «Я вернулся»; очередь возврата и отмена; отсутствие горизонтального переполнения на 390 и 1440 px. В этих сценариях ошибок JavaScript не обнаружено. Отчёт: `docs/browser-report-v0.3.json`. Снимки: `docs/*-v0.3.png`.

Проверяется настоящий локальный DemoGame через пользовательские кнопки; тест не подменяет колоду, ставки, расчёт или игровой движок. Виртуальные часы ускоряют ожидание и не изменяют поставляемые исходники. Демо-оппоненты используют обычную случайную логику.

CLI agent-browser недоступен в этой среде; использован установленный системный Chromium и Playwright. Навигация file:// блокируется политикой браузера; HTML прочитан обычным файловым инструментом и отрисован `set_content`, без запросов к file:// или localhost и без отключения политики. Поэтому это НЕ проверка браузерной онлайн-комнаты, origin, HTTPS или Telegram WebView.

## Не закрытые границы

Реальные Telegram-клиенты, публикация, HTTPS, несколько настоящих устройств, нагрузка, постоянная история, база данных и восстановление после перезапуска; независимая проверка правил/ГСЧ/безопасности; противодействие оператору сервера и сговору. Комнаты и последняя раздача по-прежнему в памяти. Перед коммерческим запуском эти работы обязательны.
